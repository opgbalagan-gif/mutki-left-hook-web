# МУТКИ — ЛЕВЫЙ ХУК

Готовая браузерная сборка вертикальной гонки на Godot 4 Compatibility / WebGL 2.0.

Игра: https://opgbalagan-gif.github.io/mutki-left-hook-web/

Игра начинается в гараже с большими колонками и оригинальным тюнингом Skyline. После первого касания играет фрагмент «МУТКИ — ХАН», диффузоры реагируют на настоящий бас. Список деталей листается свайпом; камера приближается к выбранной детали. Нажмите «ЗАЕЗД»: гаражная музыка прекращается, полная песня и движущаяся катсцена запускаются с начала. На вступлении бита управление передаётся игроку.

Телефон: газ автоматический. Тап — дрифт по направлению поворота трассы; повторные тапы поддерживают занос. Свайп вверх и удержание пальца — нитро, отпускание прекращает расход. Второй палец может тапать во время нитро. Резервные дуга и кнопки выбираются в меню паузы.

Компьютер: A/D или стрелки, Space — дрифт, Shift — нитро, R — повтор, Escape — пауза. На финишном стоп-кадре рядом с «ЕЩЁ РАЗ» есть кнопка «В ГАРАЖ».

Работает по HTTPS, без обязательных SharedArrayBuffer и многопоточности. Первичная загрузка крупная: геометрия и текстуры оригинального окружения, Skyline, гараж, музыка и звуки. Реальные iPhone/Android требуют отдельного тестирования.

Гараж, пауза, меню, таблица результатов и финиш используют общую композицию Carbon, оригинальный Latin-шрифтовой атлас и текстуры оформления. Приборы HUD сохранены. Русские подписи используют прежний читаемый шрифтовой fallback. Финиш — компактный бирюзовый X, пунктирные полосы, настоящие очки, полный стоп-кадр Skyline и команды повтора/гаража/результатов.

Технический прототип с ресурсами NFS Carbon; EA и остальные правообладатели сохраняют права на свои материалы. Лицензия на их повторное использование здесь не предоставляется. Исходная установленная игра, Unreal-проект и резервные копии в репозиторий не включены.

Сборка 14.10.2026: гараж с акустикой, прозрачные меню, тапы для дрифта, свайп вверх для нитро, более динамичная задняя камера. Дрифт больше не теряет до 29% продвижения по маршруту из-за угла кузова. Скорость после катсцены может достигать 180 км/ч, с нитро — 234 км/ч; при отпускании нитро машина плавно сбрасывает избыток скорости. Короткий текущий участок при таком темпе проходится быстрее песни. Тюнинг и рекорды хранятся локально в браузере; сохранения localhost/Wi-Fi не переносятся автоматически на новый домен. Акустические системы созданы для этого прототипа, не извлечены из Carbon.
